# 本次真实任务的文档样例

这组文档根据本仓库“标准模板与 PRD 命名优化”的已批准范围和候选文件快照生成，供阅读与评阅写作结构。它们不代表新的 Release，也不作为当前任务状态或测试结果的事实源。

从[需求概要](PROJECT_BRIEF.md)、[PRD](PRD.md)、[方案设计](PROPOSED_DESIGN.md)、[当前技术设计](TECH_DESIGN.md)和[实施计划](IMPLEMENTATION_PLAN.md)查看不同职责的写法。原始输入见 [TW-01-input.md](TW-01-input.md)，版本与范围说明见 [SNAPSHOT.json](SNAPSHOT.json)。

前四份由独立执行者根据选定只读文件生成，实施计划由主执行者按同一模板补写。独立执行者未运行检查、提交或推送；文档中的“未提供”表示快照输入限制，不表示主仓库一定缺少对应文件。当前实际检查、首轮问题与修正结果以[验证记录](../../../tests/results/template-writing.md)为准。

整理时修正了快照资料的相对链接、行尾空白，并将方案中已排除选项的比较改为既定范围下的选择依据。模板未因此扩大规则范围。用户阅读体验仍待评阅。
