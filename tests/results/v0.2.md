## 行为重放

只读评估者按需读取 `SKILL.md`、references 和 templates，对 [V26–V32](../scenarios-v0.2.md) 逐项做规则走查，七项均找到对应规则。该走查可发现规则缺漏，但场景文件含预期结果，因此不把它称为盲测通过。另有未读取预期结果的执行与行为记录，见 [独立重放](replay-v0.2.md)。

| 场景 | 规则走查 | 关键证据 |
|---|---|---|
| V26 重复接管 | 符合 | `init.md` 先审计、沿用已有地图、重跑只更新变化行 |
| V27 无产品文档 | 符合 | 代码事实不反推历史需求或批准；未知保持待澄清 |
| V28 状态跨 API/SSE/缓存 | 符合 | `routing.md` 至少 Bounded，并列传播与恢复路径 |
| V29 六类触发与反例 | 符合 | 六类触发完整；风险 Gate 优先；纯函数反例不升级 |
| V30 POC 冒充正式交付 | 符合 | `POC_VALIDATED` 不覆盖正式 AC，不进入 READY_TO_SHIP |
| V31 代码已写待测试 | 符合 | `IMPLEMENTED_UNVERIFIED` 不进入 Completed，CI 将来运行不算证据 |
| V32 已验证与授权分离 | 符合 | Task、Release 和 Shipping 三类状态各按自身证据推进 |
