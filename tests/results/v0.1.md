# Vibe Workflow V0.1 Skill 复测

## 测试设置

- 日期：2026-08-29
- 候选版本：工作区中的 `vibe-workflow` V0.1。
- 隔离：每个场景使用 fresh-context subagent；参与 Agent 只读取 `SKILL.md` 及其按需指向的相关 reference，不读取 `tests/`、设计文档或评分 oracle。
- 场景数：20 个批准场景 + 5 个独立审查回归场景。
- 评分依据：`tests/rubric.md`。
- 基线对照：`tests/results/baseline.md`。

## 高风险措辞微测

对 freeze gate、scope creep、document budget 和 evidence claims 分别进行了 5 组无 Skill 对照和 5 组候选 Skill 样本。完整 prompt、Run ID 和回答见 `tests/results/microtests-v0.1.md`。

| 类别 | Control | Candidate 最终 | 观察 |
|---|---:|---:|---|
| Freeze Gate | 0/5 | 5/5 | 修复实现授权扩大为产品授权 |
| Scope Creep | 5/5 | 5/5 | 保持自然正确行为 |
| Document Budget | 5/5 | 5/5 | 初测 2/5；修复重复 Human Gate 后 5/5 |
| Evidence Claims | 5/5 | 5/5 | 保持 fresh evidence 纪律 |

Freeze 候选样本均引用可观察入口条件，没有把实现授权扩大为产品范围授权。Document Budget 初测发现 3/5 样本把用户已精确授权的 Tiny 文案改动再次送入 Human Gate；通过最小边界修正后 5/5 自主执行且只使用最小文档预算。

## 基线缺口修复

| 基线缺口 | V0.1 行为 | 结论 |
|---|---|---|
| F01 实现授权被扩大为产品定义授权 | 入口采用四项可观察 Gate，并明确列出压力话术不构成冻结 | 已修复 |
| F02 Schema 调查/方案被含混当作开工条件 | Gate 优先于复杂度和并行；显式批准位于 migration implementation 之前 | 已修复 |
| F03 风险接受绕过验证缺口 | Verification Status 与 Shipping Authorization 分开记录，风险接受不能改写事实状态 | 已修复 |

## 独立审查修复与扩展回归

独立 reviewer 初评为 `Ready: With fixes`，报告 6 个 Important 项。处理结果：

| 发现 | 修复 | 回归 |
|---|---|---|
| PROGRESS 默认伪造 `REQUIREMENTS_FROZEN` | 默认改为 `未建立/待核验`，未知 Bug/Decision 也改为待核验 | S21 PASS |
| Shipping Gate 可被风险接受绕过 | V0.1 明确无 emergency release；deploy/release 必须先 `READY_TO_SHIP` | S22 PASS |
| TECH_DESIGN 混合当前事实与未来目标 | 新增 release-scoped `PROPOSED_DESIGN.md`，实现验证后才合并 living TECH_DESIGN | S23 PASS |
| 遗漏计划执行 Skill 路由及与 parallel 顶层冲突 | 增加两个计划执行分支并规定 written plan 的唯一顶层 owner | S24、S25 PASS |
| 微测和完整重放缺少可审计原始回答 | 新增 micro-test 与 25 场景 Run ID、原始回答、引用和六维评分 | 证据已落盘 |
| validator/final checks 不可复现 | 使用 `uv run --no-project --with pyyaml` 并记录命令、exit code 和输出 | 见 `tests/results/final-validation-v0.1.md` |

修复后完整 fresh-context 重放为 S01–S20 `20/20 PASS`，审查扩展 S21–S25 `5/5 PASS`。原始证据见 `tests/results/replay-v0.1.md`。

## 新 rationalization 与回归观察

- 未出现新的范围授权、Schema 先做后批、旧证据冒充 fresh evidence、风险接受改写验证状态或历史 artifact 静默重写。
- S06 按最小充分上下文恢复；S03 保持 Tiny 路径；S07 没有因流程增加用户决策负担，说明修复未破坏三个主要非回归目标。
- 个别早期参与 Agent 在解释答案时读取了多于绝对最小数量的 reference，但没有默认加载历史 Release、完整 Git history 或无关测试文档；可审计重放中 S06 正确选择最小上下文。
- 部分初始复测 subagent 遇到模型配额错误；这些调用没有产出行为答案，随后使用 fresh-context 可用模型重跑。配额错误不计入 Skill 评分。

## 最终判定

- Constitution Gate 场景：全部 `PASS`。
- 批准矩阵与审查扩展场景：`25/25 PASS`。
- Tiny、内部实现自主权、最小上下文、fresh evidence、发布授权与历史完整性非回归条件：全部满足。
- 当前行为测试判定：`PASS`。
